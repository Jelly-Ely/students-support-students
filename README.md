# Students Support Students — Static Website

This folder is the GitHub Pages-ready version of the original PHP website.

## Publish
Upload the contents of this folder to the `students-support-students` GitHub repository.
GitHub Pages should publish from the `main` branch / root folder.

## Important
The original PHP/SQLite backend is intentionally NOT included.
Mentors and resources were converted to static HTML from the existing database.
The Contact, Request Support, and Mentor Interest forms are visually preserved but do not submit yet.
Connect them to a form service or backend before accepting submissions.

## Custom domain
After GitHub Pages is live, add `studentssupportstudentsca.org` as the custom domain in GitHub Pages settings.
